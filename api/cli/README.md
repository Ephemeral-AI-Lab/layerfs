# @layerfs/cli

The `layerfs` command exposes LayerFS agent SDK calls as shell commands with JSON results. It requires Node.js 20 or newer and `@layerfs/agent` at the same exact version, with the agent package's external native addon on Linux or the `@layerfs/runtime` worker on macOS and Windows.

```sh
layerfs help
```

See the [agent guide](https://github.com/Ephemeral-AI-Lab/layerfs/blob/main/api/docs/agent.md#the-layerfs-command) for setup and command usage.
