## Capacity scope before enablement

Retain16MiB/4096pages as the DEFAULT scratch profile, with total graph records
N+E<=65536 and full encoded bytes<=4128768. Owner direction during this draft
now requires explicit user configuration of the temporary metadata budget.
Larger selected budgets derive and bind graph record/byte capacity rather than
keeping an independent fixed65k graph stop. This direction supersedes the earlier
fixed-only proposal; existing published profile1/2/3 evidence remains unchanged.
The pure proposed derivation is records=B/256, logicalBytes=records*63, pages=B/4096,
with checked arithmetic, page-aligned B>=16MiB and u32 discovery capacity. This
is format/admission arithmetic, not a native fit theorem or automatic support
for all representable sizes. No silent rounding/clamp/automatic growth.
Selected capacity is part of context/header/native owner binding before effects.
Every mutable node field and edge multiplicity counts; separate per-table caps
cannot replace the aggregate cap.
Exact distinct capacity refusal precedes the offending private batch. Previous
accepted private metadata remains known or exactly Unknown; no canonical namespace
construction/output begins before full validation. This capacity admission is
not prospective whole-input fit: v1 lacks an authenticated population certificate.
Above-cap graph shapes must report explicit supported-scope refusal/known cleanup,
with no fallback, quota growth, work clamp or guessed adoption.

Node/edge/index/file costs and simultaneous windows need actual native proof.
Sites maximum predecessor high-water3932pages is retained until actual graph
reuse is proved; deleting rows or using free pages does not refund16MiB ownership.
Graph begins only after Sites facts/records/projections retire known. Roots begin
only after graph nodes/edges/projections retire known. Global/native heap/cache,
physical healthy progress and Linux remain incomplete; Apple hardlimit readback0
still refuses native executable. No StrictServerMemory/concurrency enablement.
