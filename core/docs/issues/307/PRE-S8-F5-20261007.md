  fields, `provision_wire.rs` for the manifest encoding and `control.rs` for the

  authenticated manifest against the daemon-provisioned destination; create one
  deterministic temporary file exclusively, write positive-progress windows,
  rename once, then open the installed Store. Cooperating installers share that
  temporary name and all refuse an existing destination; no wait/retry or Store
  writer gate. Canonicalize its existing parent to make path aliases share the
  same ownership name. Retain partial/output files and original uncertainty on
  every failure. Sync only the global Store for Durable, never overlay backing.

  preserving `open_store`'s existing API. Reuse bounded root checks (crate-only
  visibility) and exact initial Branch/stack/root matching before acknowledging
  install. The installed Store owns one writer, fixed readers and shared cache.
- Add public-API daemon tests, with SDK only as a dev-dependency: authenticated
  local handoff, exact existing-output refusal, truncated transfer custody and
  full small-root oracle through daemon ports. Add an external macOS-host/Linux
  daemon-process proof on a fresh named in-VM volume with source/sealed host files
  unavailable to the daemon. Record both actual SQLite versions in its manifest.
- Child sockets/processes have explicit test-only bounds, and all spawned work
  is joined/stopped by the owning proof. Build first, host before Linux, one test
  invocation at a time under100s, append-only receipts. Durable builds only.
- Update architecture/current implementation docs, final scoped all-target Clippy,
  fmt/boundary/self-tests and exact LOC. F13 general control commands follow this
