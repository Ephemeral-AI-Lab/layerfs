## 1. Patch, applied only

Base files at `5a6abdbc1` are byte-identical to the v2 prototype's base, so the
two changes were applied as-is (never the whole old file):

- `connect/crates/layerfs-sandbox/src/bin/layerfs-sandbox-helper/exec.rs`:
  `use nix::sched::{setns, unshare, CloneFlags}`; the exec-stage doc; and after
  `namespaces.enter()` a `unshare(CloneFlags::CLONE_NEWNET)` block, whose
  failure ends the stage through `fail` (a setup failure is never the command's
  exit code).
- `connect/crates/layerfs-machine/src/setup/worker.rs` (`PREPARE`):
  `chmod 701 "$1"` and `chmod 700 "$1/store" "$1/sandbox"` replace the single
  `chmod 755 "$1" "$1/store" "$1/sandbox"`.

`cargo +1.85.1 fmt` wrapped the `fail(&format!(…))` call over lines; that is the
only formatting change and `cargo +1.85.1 fmt --check` is clean.
