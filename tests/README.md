# LayerFS test families

The implementation plan calls for tests covering:

- frozen formats and identity vectors;
- storage, chunking, CAS admission, packs, and copy-on-write sharing;
- workspaces, bounded streams, and structural diff;
- generic preconditions and one-dispatch publication;
- Linux OverlayFS projection and capture;
- no-fallback, no-replay, and no-recovery mechanisms;
- memory, performance, scheduler, and custody qualification.
