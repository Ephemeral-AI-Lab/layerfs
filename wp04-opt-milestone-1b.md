# WP4-M optimization milestone M1b: residual borrowed SQLite rows

## Verdict

**INCONCLUSIVE for throughput; RETAINED as a constant-factor implementation improvement.**

The semantic-correctness axis is **PASS**. The intended residual copy-elimination mechanism is **PASS**. The controlling throughput claim is **INCONCLUSIVE / GATE-FAILED** because the affected median improved 1.758%, below the precommitted 5% threshold, even though all 5/5 balanced interleaved pairs improved. M1b is retained under the explicitly separate retention rule: it deterministically eliminated 100% of the targeted residual row-to-Vec bytes, preserved identity and boundedness, and produced no repeatable protected regression of 5% or more.

This is not profile-selection evidence. qualification=false, promotion=false, and rejection=false remain unchanged. No asymptotic throughput or promotion claim is made.

## Hypothesis and causal scope

After accepted M2, reconstruction already used bounded per-leaf batches of at most K=64 references. The remaining per-object raw SQLite paths were pre-COMMIT closure traversal, fresh full scrub, and small range reads. The narrow hypothesis was that inspecting those raw canonical BLOBs through rusqlite's borrowed row value would remove their avoidable Vec copies without touching M2 reconstruction, codecs, identity, transaction semantics, or timer boundaries.

The accepted-M2 executable was frozen before the edit. M1b changed only the candidate benchmark source after that freeze. There was no public decode_mapping Vec-to-slice signature change and no duplicate reconstruction implementation.

## Minimal implementation

- Added one private Store::with_borrowed_bytes callback helper.
- The helper executes the existing single-object SELECT, requires a BLOB through row.get_ref(...).as_blob(), records the SQL/BLOB observation, authenticates the canonical bytes against the requested ObjectId before the callback, and propagates typed SQLite, identity, and callback failures.
- Routed only residual per-object raw reads through that helper: non-batched stream_file (the pre-COMMIT path), scrub raw chunks, and range raw chunks.
- Reused the accepted M2 for_each_leaf_bytes bounded reconstruction branch unchanged.
- Left mapping reads and the public codec API unchanged.
- Added Observed counters for borrowed row BLOB reads/bytes. Bytes inspected through borrowed values are not counted as row-to-Vec copy bytes.

SQLite remains authoritative. Canonical bytes, ObjectIds, raw ChunkIds, ordering, duplicates, exact Q, one publication COMMIT, receipts, and timer boundaries are unchanged.
