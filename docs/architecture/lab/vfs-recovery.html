Recovery

Fresh requested / prior / different readback. Never issue a second publication COMMIT.

Publication contract

One state transition; no hidden second authority.

Invariant
  1. Construct and authenticate immutable objects.
  2. Make required bytes durable.
  3. BEGIN one writer transaction.
  4. Check expected head.
  5. Install locator, root, transition, and receipt.
  6. Update visible head.
  7. Dispatch exactly one publication COMMIT.
  8. If ACK is lost, reconcile from a fresh durable read.

Claim boundary

What this lesson does not authorize.

Not production qualification
  • G5 is benchmark-mechanism PASS, not VFS/SDK product qualification.
  • Exact and sparse projector samples are warm, 250,000-byte, process-lifetime-seed evidence.
  • Different-length native projection is correct FullFallback; it has no G5 fast claim.
  • APFS clone evidence does not qualify Linux, Windows, or a canonical reflink format.
  • Native export, full reads, Verified scrubs, and full tracing GC remain linear.
  • Projection failure never invalidates an already accepted logical commit.
