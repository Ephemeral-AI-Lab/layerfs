Lesson 01 · Equality domains

Same width does not mean same identity.

LayerFS currently reuses one 32-byte ObjectId wrapper across several roles. Equality remains role-scoped: payload, mapping, operational file, semantic content, inode, commit, and namespace answer different questions.

Typed fetch algorithm

Verify bytes first; decode role second

fetch_typed<T>(id):
  locator = index.lookup(id)
  bytes   = carrier.read(locator)
  require BLAKE3("layerfs/object\0" || bytes) == id
  value   = canonical_decode_exact(bytes)
  require value.role == T
  return value

Worst and failure cases

Five substitutions that fail closed

Locator → ObjectId

Carrier, path, offset, and pack ID can change while canonical bytes stay equal.

Native digest → FileStateRoot

A derived cache may be absent, stale, or rebuilt. It cannot mint authority.

ContentDigest → FileStateRoot

Equal bytes need not imply equal operational structure, profile, or history.

NamespaceRoot → authority token

An immutable directory root cannot encode a mutable head generation.

CommitId → RequestId

History identity and at-most-once publication identity answer different questions.

Trusted receipt → Verified authority

Trusted assumptions never become receipt-covered Verified evidence.
