CD32–64 seeks canonical rejoin under hard node bounds

Canonical builder algorithm

Roles and output levels enter the cut domain. The root uses the lowest legal top level.

Specification
for each complete leaf occurrence or child descriptor:
  cut_preimage = DOMAIN
               || role_u8
               || output_level_u8
               || u32be(entry_bytes.len)
               || entry_bytes
  marker = (BLAKE3(cut_preimage)[0] & 0x1f) == 0

  append entry
  if local_position in 32..63 and marker:
      close node including marker       // natural
  else if local_position == 64:
      close node including entry        // forced

at EOF:
  emit final tail, which may be < 32
  emit the lowest legal minimal root
  reject alternate partitions on decode

Correctness never depends on a probable marker match. Rejoin requires old/new cursor alignment, a scanner-reset boundary, and authenticated occurrence/node identity. Without both CDC and tree convergence, continue one explicit suffix fallback or fail before publication.
