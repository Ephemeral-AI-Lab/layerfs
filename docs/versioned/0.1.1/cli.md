# LayerFS 0.1.1 CLI reference

> **Status:** Released compatibility record for `v0.1.1`.

The 0.1.1 release does not add or remove a documented CLI operation. Its
command grammar, context ownership, typed identifiers, query paging behavior,
fresh-process execution, explicit Commit, reconciliation, Add, and End
semantics remain those in the [0.1.0 CLI reference](../0.1.0/cli.md).

Internal initialization diagnostics and benchmark controls are not CLI API.
