# LayerFS 0.1.1 release-candidate CLI reference

> **Status:** Candidate compatibility record; `v0.1.1` is not published.

The 0.1.1 candidate does not add or remove a documented CLI operation. Its
command grammar, context ownership, typed identifiers, query paging behavior,
fresh-process execution, explicit Commit, reconciliation, Add, and End
semantics remain those in the [0.1.0 CLI reference](../0.1.0/cli.md).

Before publication, every documented command and negative case must be run
against the exact clean release source. Internal initialization diagnostics
and benchmark controls are not CLI API.
