# LayerFS 0.1.2 CLI reference

> **Status:** Released for LayerFS 0.1.2.

The 0.1.2 release does not add or remove a documented CLI operation. Its
command grammar, context ownership, typed identifiers, query paging behavior,
fresh-process execution, explicit Commit, reconciliation, Add, and End
semantics remain those in the [0.1.1 CLI reference](../0.1.1/cli.md). The new
owner-side range-edit operation is Rust SDK-only; no CLI grammar was added.

Initialization diagnostics, benchmark controls, and benchmark-only seed
overrides are not CLI API.
