These are not public FUSE-path acceptance, a V1 result, a sealed candidate, or
benchmark evidence. The retained canonical Store fixture is initialized once per
test; its native source directory is removed before the host reads it.

## Component scope and next executable work

`HostOverlay` now owns the proven Overlay/Index/Payload/Ranges and Budget
resources, one immutable Store reader and one monotonic `OriginSequence`.
Acquisition imports only the looked-up canonical inode/binding, preserving the
canonical-to-live alias map and newer live inode revisions. Ordinary metadata
operations prepare under existing FIFO admission; installation is one leased-root
comparison and replacement. Captured snapshots never acquire that mutation queue.

Still required before adapter acceptance: the existing live inline and logical
spool limits (independent of physical allocation); public generic-FUSE routing,
kernel lookup/FORGET and open ownership, fsync/cache/SDK coherence; V1 writable
mapping visibility; Commit lifecycle/construction integration. These remaining
obligations are not covered by the three component passes.

## Subsequent quota and kernel-ownership result

Attempt 03 establishes the prior logical quota obligation at this component:
ordinary writes accept exactly four spool bytes, a captured reader keeps those
bytes charged after live truncate, and a rejected append does not advance its
source highwater. Releasing that reader and bounded reclamation restore capacity.
Eight 1 MiB SDK inline edits reach the cumulative 8 MiB limit; a further byte is
rejected without changing the root. Truncate updates the live inline aggregate
while an older snapshot remains readable. SDK 1 MiB Inline remains valid with
`max_spool_bytes = 0`; ordinary write is rejected under that policy. Both backing
classes retain their physical storage charges.

Kernel lookup counts are u64 records in the same disk index as the inode graph.
The zero-to-one transition retains one inode pin; the final counted FORGET removes
that pin. Entry mutation and this ownership change share one private candidate.
Attempt 04 establishes two lookup references, counted/over-counted FORGET,
independent open ownership, namespace rollback when lookup count would overflow,
131 directory references selected through bounded pages, two detach batches and
harmless late FORGET after detach. These are host-component results; actual
kernel transport/reply cancellation and generic mmap visibility remain open.


## Numeric cookies and host transport dispatch

`dispatch-cookie-attempt01.json` records the exact binary, source/dependency
hashes, compile command and two exact test commands. Both execute one test and
pass. Directory enumeration handles 301 canonical names plus dots in three
bounded pages, preserves distinct cookies for hardlink aliases, resumes after a
removed cookie, releases partial-page kernel references, and retains only 300
current cookie rows after deletion and 64 create/remove cycles. No daemon map
contains the full directory.

The dispatch check retains the original request and reply, verifies exact replay
without another mutation, rejects the same ID with changed request bytes, and
checks known operation failures, stale requests and unknown sessions. A removed
inode remains readable while its kernel reference exists; counted FORGET removes
its live owner while an older Snapshot continues reading the captured bytes.
This test calls the real host codec/handler; network client integration remains
separate work, and it is not a generic-FUSE V1 snapshot pass.


A later adversarial review found that the server's full-frame digest also bound
an independently advancing acknowledgment watermark. `replay-ack-attempt01`
adds the concrete sequence-2 retry with the same mutation and acknowledgment
advancing from 0 to 1; it fails with Invalid as predicted. Attempt02 hashes only
the operation bytes under the already bound session/sequence and passes the
same complete server check. Both attempts and exact source hashes remain. The
numeric directory check is unaffected and is retained without another run.
