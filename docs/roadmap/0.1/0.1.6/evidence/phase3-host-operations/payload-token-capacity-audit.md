## Concrete admission defect inferred from source

`OverlayPolicy::default` sets `max_payload_owners = 8192` (`layerfs-workspace-core/src/limits.rs:58`). `overlay_budget::components` budgets 80 resident bytes per such owner and supplies this value to `PayloadLimits.owners` (`overlay_budget.rs:175,198`). This represents bounded transient owned handles/release tickets, not an adequate disk-token capacity for a million changed files.

The actual `Payload` implementation uses a single `State.owners` counter for every persisted TOKEN row. `write_classified` (`overlay_payload.rs:324`), `append` (`:514`), and `own_interval` (`:687`) reject when this counter plus pending write reservations reaches `limits.owners`. Each newly installed token increments it (`:390,:622,:756`). Dropping an `OwnedRange` merely queues release of its one reference. `reclaim_step` (`:810`) releases that reference and pops the queue. If an immutable metadata leaf still owns the token, the token and the counter remain. The counter decrements only after the token's last reference is released and its bounded interval-removal job finishes (`:1061`).

The ordinary path is `HostOverlay::write` → `Ranges::append_from`/raw piece construction → `Payload::write_from`; `Ranges` persists token ownership with `Index::set_owned` (`overlay_ranges.rs:603`). Thus distinct live files retain disk tokens even after their transient `OwnedRange`s and release queue entries are gone. The current admission condition predicts rejection at the 8,193rd independent live ordinary payload token under default owner limits, despite adequate existing index/payload disk quotas and no 8,193 live resident handles. This exact failure point is **not yet experimentally verified**. Other metadata or reclamation conditions might fail earlier and must be recorded separately if the first reproducer finds them.

There is also no bounded retired-handle admission assist in the owner-producing paths: queued `OwnedRange` drops wait for explicit maintenance. A correction must keep the release queue bounded and avoid treating a transient queue backlog as a permanent persisted-file ceiling.
