# LayerFS 0.1.1 baseline — 2026-09-02

> **Status:** Append-only planning checkpoint; not release evidence or a
> product contract. The live checklist is [README.md](README.md).

## Source position

- `main`, `origin/main`, and annotated tag `v0.1.0` resolved to
  `243f98a3bf287d6a9f8168891452b7355d45529c`.
- LayerFS 0.1.0 was published as a source-only Developer Preview on
  2026-09-01.
- No 0.1.1 candidate existed.

## Observations

- `tools/test-fast.sh` passed with 59 seconds of warm test execution; its cold
  invocation, including compilation, took 120.8 seconds.
- The default suite did not run real FUSE unless `LAYERFS_LIVE_FUSE` was set.
- The Docker integration test only checked `docker info` when
  `LAYERFS_LIVE_DOCKER` was set.
- Workspace candidate construction built complete base and final namespace
  manifests under the documented final-delta memory bound.
- An exploratory public-CLI import of 9,000 empty files stayed CPU-bound in
  `layerstack init` for more than three minutes and was interrupted. It never
  reached Branch fork, Workspace create, or Commit, so it proved no Workspace
  or final-delta failure.

## Decisions

- Give 0.1.1 one goal: measure and harden the existing-directory through
  localized-Commit lifecycle at large namespace sizes.
- Use real FUSE for every timed namespace row.
- Use 100, 1,000, 10,000, and 100,000 regular files, each with 2,500
  deterministic unique bytes, for 0.25 MB through 250 MB fixtures.
- Add one LayerFS-only namespace runner. Keep Cloudflare Computer out of the
  namespace campaign and run the existing paired payload campaign only after
  candidate stability.
- Open one admission issue now, assigned to `@yifanxuaaa`; create fix and
  release issues only when evidence warrants them.
- Preserve the 0.1.x contract. Do not publish 0.1.1 if no patch-worthy defect
  is admitted.
- Move prepend transfer optimization, `copy_file_range`, borrowed ranges, and
  broader mixed-edit resilience to 0.1.2.
- Create the immutable 0.1.1 manual and release record only after a candidate
  passes the gates.

## Next evidence

Implement the four-tier namespace runner, capture one 0.1.0 sample per tier,
and record separate initialization, Branch fork, real-FUSE Workspace create,
ten-byte edit, Commit, End, and fresh-reopen results before selecting a fix.
